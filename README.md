# دفترچه‌ی روزانه — فاز صفر

اپ محلی (local-first) که فقط روی خود دستگاه کار می‌کند؛ بدون سرور، بدون اینترنت.

## اجرا

```bash
npm install
npm run dev       # حالت توسعه
npm run build     # بیلد نهایی (شامل service worker برای آفلاین)
npm run preview   # اجرای بیلد نهایی برای تست
```

## چی داره

- تیک عادت‌های روزانه + استریک ساده
- یادداشت سریع (بولت‌ژورنال ساده)
- مرور روزانه (چند خط)
- نصب‌شدنی روی گوشی (PWA) و کاملاً آفلاین

## معماری داده

همه‌چیز در یک جدول واحد در IndexedDB (`src/db.ts`) با شکل:

```ts
{ id, type, payload, updatedAt, deleted, deviceId }
```

این شکل عمداً همینه که بعداً وقتی سرور sync اضافه شد، بدون تغییر schema
سرور، قابلیت‌های جدید (فقط سمت کلاینت) اضافه بشن. حذف‌ها به‌صورت
tombstone (`deleted: true`) هستن، نه حذف فیزیکی — برای فازهای بعدی که
چند دستگاه با هم sync می‌شن لازمه.

تاریخ‌ها با تاریخ محلی دستگاه ذخیره می‌شن (نه UTC) تا نیمه‌شب‌های
۰۰:۰۰–۰۳:۳۰ ایران باعث جابه‌جایی «روز» نشه.
