# رنگ‌های اپ — وضعیت فعلی

منبع: `src/index.css`. هر تغییری این‌جا داده بشه، باید توی همون فایل هم اعمال بشه — این فقط مستنده، خودکار sync نمی‌شه.

## توکن‌های اصلی (متغیرهای CSS در `:root`)

هر جای اپ که از این متغیرها استفاده می‌کنه، با تغییر مقدار متغیر همه‌جا هم‌زمان عوض می‌شه.

| متغیر | مقدار | نقش | استفاده در |
|---|---|---|---|
| `--paper` | `#EAE6D9` | پس‌زمینه‌ی کلی صفحه (رنگ کاغذ) | `body`, پس‌زمینه‌ی ورودی‌ها و دکمه‌های خنثی |
| `--paper-line` | `#CFC7AC` | خط‌های خط‌دار پس‌زمینه، بوردر کارت‌ها و ورودی‌ها | خط‌های دفترچه، بوردر `.card`، `.switch` خاموش |
| `--ink` | `#242320` | متن اصلی، دکمه‌های تیره | متن پیش‌فرض، دکمه‌های مشکی (`.mini-btn`, `.add-row button`) |
| `--ink-soft` | `#5B5648` | متن کم‌رنگ‌تر/فرعی | زیرنویس‌ها، برچسب‌ها، آیکون‌های غیرفعال |
| `--teal` | `#2F6F5E` | رنگ تأیید/تکمیل‌شده | چک‌باکس تیک‌خورده، سوییچ روشن، هاور دکمه‌ها |
| `--teal-soft` | `#DCE7E0` | پس‌زمینه‌ی ملایم تیل | ردیف در حال ویرایش جدول خواب، کارت آخرین ورودی پروژه |
| `--rust` | `#A63D2F` | رنگ هشدار/فوریت | متن روزهای باقی‌مانده‌ی پرداخت، بوردر جمعه |
| `--rust-soft` | `#F1DCD6` | پس‌زمینه‌ی ملایم هشدار | ردیف پرداخت نزدیک به موعد، پس‌زمینه‌ی دکمه‌ی جمعه |
| `--gold` | `#B8842A` | رنگ حالت/mood فعال | دکمه‌ی mood انتخاب‌شده در مرور روزانه |
| `--card` | `#F3F0E4` | پس‌زمینه‌ی کارت‌ها | همه‌ی `.card` |
| `--shadow` | `0 1px 0 rgba(36,35,32,.06)` | سایه‌ی ظریف زیر کارت‌ها | `.card` |
| `--nav-bg` | `#FBFAF8` | پس‌زمینه‌ی نوار ناوبری پایین | `.bottom-nav` |
| `--nav-active-bg` | `#FEF4EE` | پس‌زمینه‌ی قرص تب فعال در نوار پایین | `.bottom-nav-item.active .bottom-nav-icon` |
| `--nav-icon` | `#D23323` | رنگ آیکون (و برچسب فعال) نوار پایین | `.bottom-nav-icon`, `.bottom-nav-item.active .bottom-nav-label` |

## رنگ‌های ثابت (هنوز توکن نشدن — مستقیم توی CSS نوشته شدن)

اگه بخوای این‌ها هم قابل تغییر مرکزی بشن، باید به یه متغیر جدید تبدیل بشن.

| رنگ | نقش | جای استفاده (selector) |
|---|---|---|
| `#FFFFFF` | متن سفید روی پس‌زمینه‌ی تیره | `.switch-thumb`، متن ردیف‌های "دیرکرد"/"فوری" (`.pay-row.overdue`, `.log-item.due-urgent`) |
| `#F1E5C9` | پس‌زمینه‌ی کار با موعد نزدیک (زرد) | `.log-item.due-soon` |
| `#E53935` | پس‌زمینه‌ی کار با اولویت (قرمز) | `.log-item.priority`, `.type-btn.holding-priority`, `.type-btn.priority-pending` |
| `rgba(0,0,0,.25)` | سایه‌ی دایره‌ی سوییچ | `.switch-thumb` |
| `rgba(229,57,53,.5)` | هاله‌ی درخشش دور کار اولویت‌دار | `.log-item.priority` (`box-shadow`) |

## فونت

- فونت اصلی: `IRANSansX` (وزن‌های ۴۰۰ تا ۸۰۰)، fallback به `Vazirmatn` و سیستم
- فونت اعداد تایمر/ساعت: `JetBrains Mono`

## نکته درباره‌ی نوار ناوبری پایین

سه رنگ خواسته‌شده (`#FBFAF8`, `#FEF4EE`, `#D23323`) به‌عنوان توکن جدید اضافه شدن، نه این‌که رنگ‌های موجود جایگزین بشن — چون نوار پایین بصری کاملاً جدا از بقیه‌ی اپه (شبیه اپ‌های دیگه‌ست، نه هم‌رنگ کاغذ/جوهر فعلی).
